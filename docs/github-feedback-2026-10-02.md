# GitHub 反馈改进（2026-10-02）

对应 [#1](https://github.com/jimmgreen/LumaShot/issues/1)、[#2](https://github.com/jimmgreen/LumaShot/issues/2)、[#3](https://github.com/jimmgreen/LumaShot/issues/3)。

- `Ctrl+Alt+O`：框选后自动识别、复制文字并关闭截图界面。成功使用系统通知，不需要再关闭弹窗。识别失败、没有文字或剪贴板忙时保留选区，Enter 重试，Esc 取消。设置中可以更换或清除快捷键。
- `Ctrl+Alt+P`：框选后直接创建置顶贴图。已有截图选区也可按 F3 贴图、O 快捷识别复制。
- “截图与粘贴”设置可选择 OCR 快捷复制是否删除空白。默认保留空格和换行，避免改变英文、代码和表格内容；普通 OCR 贴图仍可选字、标记和多次复制。
- 设置中可选择兼容的本地 ONNX 模型目录，也可恢复内置模型。兼容范围见 [自定义 OCR](custom-ocr.md)。不支持把任意 OCR 服务地址或不兼容模型直接作为引擎。
- 主截图工具栏使用图标，悬停显示操作说明；属性面板保留数值和必要文字。
- 矩形、椭圆、箭头、画笔工具在选区画布上可滚轮调整线宽，Shift 加速。绘制过程中、繁忙状态及选区外不调整；属性控件原有滚轮调值保留。
- 普通剪贴板面板每次主动唤起靠近鼠标，贴边侧栏和固定面板保留各自位置。
- 剪贴板 `Ctrl+Shift+Enter` 粘贴去空白文本；`Shift+Enter` 仍只去掉富文本格式、保留文字间距。原始历史内容不改动。

本次不自动回复或关闭 GitHub issues，也不安装或替换已安装的应用。
