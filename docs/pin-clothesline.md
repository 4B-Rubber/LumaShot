# 钉图晾衣绳（Pin Clothesline）

把暂时不用的钉图“晾”到屏幕顶部的一根绳子上，需要时再取回。交互原型见仓库外的 `lumashot_pin_clothesline.html`。

## 交互

| 操作 | 结果 |
| --- | --- |
| 拖动钉图到屏幕顶部 150 DIP 内 | 绳子垂下，出现插入空位；钉图变半透明 |
| 在该区域松手 | 钉图以缩略图挂到绳上，窗口隐藏 |
| 钉图获得焦点时按 `H` | 直接挂到绳上（缩略图从原处飞上去） |
| 鼠标悬停在钉图上 | 图片右上角淡入两个按钮（160 ms）：衣架 = 晾到绳上，× = 关闭；悬停时按钮变色并在下方显示“晾到绳上 (H)”/“关闭” |
| 点击 × | 钉图约 140 ms 淡出后关闭 |
| 鼠标靠近屏幕顶边 70 DIP 内 | 顶边出现蓝色光晕（越近越亮），顶部中间滑下提示条“晾着 N 张 · 停在顶部展开” / “晾衣绳 · 停在顶部展开” |
| 鼠标**静止**停在屏幕最顶端一行（或提示条上）约 350 ms | 中间亮条由中心向两侧长满，随后绳子落下（有打开的钉图或绳上有钉图时，且没有按下鼠标键） |
| 前台是最大化窗口（顶端是标签页 / 菜单） | 停在最顶端要约 600 ms；停在提示条上仍是 350 ms |
| 前台是全屏程序（游戏、视频、演示、F11 浏览器等） | 不出现光晕，也不计时：全屏程序的菜单栏、标签栏就在顶端 |
| 刚松开鼠标键（点了顶端的标签、拖窗口到顶端） | 400 ms 内不开始计时 |
| 绳上没有钉图时 | 绳下显示虚线提示“把钉图拖到这里晾起来，或在钉图上按 H” |
| 单击缩略图 | 钉图飞回原位置与原缩放 |
| 按住缩略图向下 / 远处拖 | 从夹子上扯下，直接进入系统拖放：拖到其他程序（微信 / QQ 输入框、浏览器、Word、资源管理器等）松手即插入图片，卡片随后飞回绳子；松手处没有程序接收（空白处、LumaShot 自己的窗口）时照常放成钉图，回到绳子区域则重新挂上；拖动中按 `Esc` 卡片飞回绳子 |
| 按住 `Shift` 扯下缩略图 | 旧行为：只作为普通拖动，把它放成钉图 |
| 普通钉图上按住 `Ctrl` 拖动 | 系统拖放到其他程序；插入后钉图回到原位，没有程序接收时照常移动到松手处（不按 `Ctrl` 仍然只是移动） |
| 绳上操作条：全部取下 / 收起 | 依次取回全部钉图 / 收起绳子 |
| 鼠标离开绳子区域约 600 ms | 绳子自动收起 |

## 实现

- `src/pin/clothesline_model.h`：纯模型（布局、绳子形变叠加、摆动物理、命中测试），无 Win32 依赖，可单元测试。
- `src/pin/clothesline.{h,cpp}`：`Clothesline` 类。每个 `PinManager` 一个分层窗口（`LumaShot.Clothesline`，WS_EX_LAYERED | TOPMOST | NOACTIVATE | TOOLWINDOW），首次使用时创建；D2D 内存目标 + `UpdateLayeredWindow`；文字统一经 `TextRenderer`。
- 帧节拍：动画期间由 `FramePacer` 工作线程等待绳子所在显示器的垂直消隐（`IDXGIOutput::WaitForVBlank`），每次刷新投递一条合并的 `WM_APP+0x31` 帧消息（处理完再确认，慢帧不会堆积、不会饿死输入）；拿不到垂直消隐或它不阻塞（显示器休眠、部分虚拟显卡）时改用 DWM 刷新周期的高精度可等待计时器；线程创建失败才退回 15 ms `WM_TIMER`。线程首次动画时创建，静止时阻塞在条件变量上，不是常驻循环。
- 物理步长：用 QueryPerformanceCounter 计时（`GetTickCount64` 只有 15.6 ms 精度），按 60 Hz 帧折算并拆成不超过 1 帧的子步，60 / 144 Hz 下摆动一致；卡顿后最多补 2.5 帧。
- 绘制开销（软件 D2D + `UpdateLayeredWindowIndirect`）：已挂好的卡片（阴影 + 纸 + 缩略图 + 夹子）预渲染为精灵，每帧一次旋转贴图；操作条与空绳提示同样烘焙，按整像素放置保持文字清晰；绳子连续两帧不变（只有卡片在摆）时烘焙成横条位图直接贴；只清除并提交上一帧/本帧有内容的行（`prcDirty`）；布局变化时动画中沿用旧缩略图缩放绘制，静止那一帧再精确重采样，避免一帧内重采样全部卡片的卡顿。
- 轮询：“已武装”（有可见且未挂起的钉图，或绳上有钉图）时 100 ms 轮询光标；光晕 / 提示条 / 停留亮条显示期间提高到 16 ms，消失后回到 100 ms；没有钉图时停止轮询。没有常驻循环。
- 顶边触发规则（`ClotheslineEdge`，纯状态机，单元测试覆盖）：
  - 静止：计时开始时记下光标位置，任一方向移动超过 4 DIP 就重新计时。沿着顶端菜单栏 / 标签栏横向移动永远充不满亮条。
  - 前台窗口判断（`ClotheslineEdge::Current`，只在光标进入顶边 70 DIP 内时查，最多每 250 ms 一次）：取前台根窗口；LumaShot 自己的窗口、桌面（Progman / WorkerW / GetShellWindow）、任务栏不算；不在光标所在显示器上也不算（另一块屏上的全屏视频不影响这块屏）。在本屏时，`SHQueryUserNotificationState` 返回 QUNS_BUSY / QUNS_RUNNING_D3D_FULL_SCREEN / QUNS_PRESENTATION_MODE 即视为全屏；否则看窗口本身（`Classify`）：盖满整个显示器且没有标题栏、或盖满但未最大化 → 全屏；最大化 → 最大化（任务栏自动隐藏时最大化窗口也会盖满显示器，仍算最大化）。
  - 全屏：光晕、提示条、停留亮条都不出现。最大化：最顶端停留 600 ms（提示条是明确目标，仍 350 ms）。
  - 按住左 / 右 / 中键时不计时；松开后 400 ms 内也不计时。
- 顶边光晕：每个 `Clothesline` 一个单独的分层窗口（`LumaShot.ClotheslineGlow`，额外带 WS_EX_TRANSPARENT，鼠标点击穿透），覆盖光标所在显示器顶部 64 DIP，空闲时隐藏。`PinManager::Create` 调用 `Clothesline::Arm()` 创建绳子窗口并开始轮询。
- 钉图悬停按钮：`Pin::ToolRects`（28 DIP，间距 4，边距 6，图片宽 < 72 或高 < 40 DIP 时不显示）；只画在钉图自己的渲染目标上，复制 / 保存的图片不含按钮。锁定、标注编辑、拖动、挂起、飞行、关闭中均隐藏。计时器 105 = 淡入淡出，106 = 关闭淡出。衣架图标与绳子提示条共用 `CreateHangerIcon`。
- `PinManager`：`HangPin` / `DropOnLine` / `EndLineDrag` / `RetrievePin` / `DetachPin` / `FlyStep`。挂起时钉图窗口隐藏但保留，位置不变；取回动画用窗口计时器 104（320 ms，缩放三次缓出，位置带轻微回弹）。
- 拖出到其他程序（`src/export/drag_out.{h,cpp}`，`PinManager::DragOut`）：OLE `DoDragDrop`，只允许 `DROPEFFECT_COPY`。数据对象提供 `CF_HDROP`（`%TEMP%\LumaShot-Clipboard\LumaShot-年月日-时分秒-毫秒.png`，格式跟随“截图粘贴为文件”设置，关闭时用 PNG）、`CF_DIB` 和 `PNG`；拖动一开始就在工作线程编码，目标提前读取时等待编码完成。被接收后文件保留，由现有 24 小时清理删除；没被接收时文件随数据对象释放删除。拖动期间钉图窗口加 `WS_EX_TRANSPARENT`（分层窗口不参与命中测试），继续跟随光标；在可接收的程序上变成淡影（alpha 110），在绳子区域显示插入空位（alpha 150）。LumaShot 没有注册任何拖放目标，所以松手在自己的窗口上等同“没有目标”。没有目标时不显示“禁止”光标。扯下卡片后通过 `WM_APP+0x48` 投递开始拖放，等绳子的鼠标处理返回；只在左键（交换按键时为右键）实际按住时开始，所以合成消息的测试仍走普通拖动。`DoDragDrop` 失败时继续普通拖动。
- 坐标：屏幕位置为物理像素，绳子按所在显示器 DPI 缩放（Per-Monitor V2）。

## 会话

“挂起”状态**会持久化**：会话索引（`%LOCALAPPDATA%\LumaShot\pin-session\session.index`，升级 / 重装 / 卸载都保留）第 2 版给每张钉图多存一个 `hung` 标志，位置仍是钉图原来的位置（取下时飞回去的地方）。电脑重启、软件重装或重新启动后，挂着的钉图恢复为隐藏状态并重新挂回绳上（`Clothesline::Restore`：不飞行、不放下绳子，按保存顺序排列），要用时照常停在顶边放下绳子取回；没挂的钉图照常显示在原处。旧版（第 1 版）索引照常读取，其中的钉图按未挂起处理。挂起（H / 衣架按钮 / 拖到绳上）和取下都会写入会话。关闭挂起的钉图会把它从绳上移除。
绳子换到另一块显示器（或恢复后第一次定位）时按新宽度和缩放重新排布卡片。

## 测试

`build\lumashot_clothesline_test.exe`（ctest 名 `pin_clothesline`）：模型单元测试、真实绳子窗口（挂上 / 拖放预览 / 单击取回 / 全部取下 / 收起）、PinManager 集成（H 挂起、取回飞行落点、扯下续拖、关闭移除）。另测顶边光晕（出现 / 点击穿透 / 16 ms 轮询 / 停留亮条 / 远离后隐藏 / 无钉图停止轮询）、顶边触发规则（静止 350 ms 触发、最大化 600 ms、提示条 350 ms、全屏无光晕无计时、沿顶端滑动不触发、几像素手抖仍算静止、松开鼠标后等 400 ms、按键打断计时、窗口分类：无边框盖满 = 全屏 / 普通 / 最大化 / 任务栏自动隐藏的最大化）、空绳提示、钉图悬停按钮（淡入淡出、高亮、按下不触发拖动、衣架挂起、锁定隐藏、移出取消、× 淡出关闭）。画面输出到 `build\agent\` 下的 `clothesline.bmp`、`clothesline-glow.bmp`、`clothesline-empty.bmp`、`pin-hover-close.bmp`、`pin-hover-hang.bmp`。测试不移动用户光标。另有性能段：10 张卡片、3840 px @150% 下打印每帧开销（清除 / 绳子 / 卡片+刷新 / 提交）与实际帧间隔（中位数、抖动、迟到帧），只设宽松上限。

`build\lumashot_pin_session_test.exe`（ctest 名 `pin_session`）另测挂起状态持久化：`hung` 标志读写、第 1 版索引兼容、挂起后重启仍隐藏在绳上且不放下绳子、未挂的照常显示、家位置保留、取下后再重启正常显示。
