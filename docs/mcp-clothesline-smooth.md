# 钉图晾衣绳：卡片摆动掉帧优化（2026-10-10）

## 原因
1. **节拍**：15 ms `SetTimer` 实际按 15.6 ms 系统节拍触发（约 64 Hz），与 60 / 144 Hz 刷新拍频，周期性重复/跳帧；`GetTickCount64` 计时精度 15.6 ms，物理步长在 0 / 0.94 / 1.87 帧之间跳。
2. **单帧开销**：4K@150% 的绳子窗口 3840×450，每帧软件重绘：每张卡 4 层圆角阴影 + 纸 + 缩略图 + 夹子，操作条文字每帧排版，整窗 `UpdateLayeredWindow`。
3. **中途卡顿**：布局缩放变化时一帧内对所有卡片 CPU 重采样缩略图。

## 改动（`src/pin/clothesline.{h,cpp}`）
- `FramePacer`：动画期间工作线程 `WaitForVBlank`（绳子所在显示器），每次刷新投递一条合并的帧消息，处理完才确认；不可用时用 DWM 刷新周期的高精度可等待计时器；静止时线程阻塞（非常驻循环）；线程失败才退回 `WM_TIMER`。
- QPC 计时 + ≤1 帧子步，60 / 144 Hz 摆动一致。
- 卡片精灵（含 2 px 透明边，旋转边缘平滑）、操作条/空绳提示烘焙（整像素放置）、绳子静止两帧后烘焙为横条位图。
- 只清除/提交有内容的行（`UpdateLayeredWindowIndirect` + `prcDirty`）。
- 动画中沿用旧缩略图缩放绘制，静止帧再精确重采样。
- 顶边光晕的衣架图标几何缓存。
